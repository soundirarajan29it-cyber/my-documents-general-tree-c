# My Documents General Tree in C

## Project Description
This project models the "My Documents" folder in a PC using a General Tree Data Structure in C language.

A General Tree allows a node to have multiple child nodes. In this project:

- Root node represents "My Documents"
- Sub-folders are represented as child nodes
- Infinite folder hierarchy can be created

## Concepts Used
- General Tree
- Structures
- Dynamic Memory Allocation
- Recursion
- Arrays of Pointers

## Folder Structure Example

My Documents
├── College
│   ├── Semester 1
│   └── Semester 2
├── Photos
└── Projects
    ├── C++ Project
    └── DSA Project
